# Mobile App Development - State Management

## Features
- Counter App (StatefulWidget)
- Navigation between screens
- Lifecycle demo with Timer
- Todo App (add, delete, checkbox)

## Branches
- main → documentation only
- counter-app → counter + navigation
- lifecycle → lifecycle implementation
- todo → todo app with checkbox feature

## Screens
- Counter Screen
- Lifecycle Screen
- Todo Screen

## Technologies
- Flutter
- Dart
- StatefulWidget
- setState (State Management)

## Description
This project demonstrates basic state management concepts in Flutter using StatefulWidget and setState. It includes multiple mini apps such as a counter, lifecycle demo, and a todo application with checkbox functionality.
